3

Классический макет

средненовоеавтопроверка

Разложи блоки как у большинства сайтов:

  • шапка header — сверху на всю ширину
  • под ней в ряд: меню aside слева (ширина 200px) и контент main — всё остальное место
  • подвал footer — внизу на всю ширину

Подсказка

Оберни aside и main в flex-контейнер (он уже есть — .middle). Чтобы main занял остаток, дай ему flex-grow: 1.

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>

        body { margin: 0; font-family: sans-serif; }
        header, aside, main, footer { padding: 20px; color: white; }
        header { background-color: #6d4aff; }
        aside { background-color: #ff4d8d; }
        main { background-color: #19b8a6; flex-grow: 1; }
        .middle { display: flex; }
        aside { width: 200px; }
        footer { background-color: #1f1b3d; }
    </style>
</head>
<body>
    <header>Шапка сайта</header>
    <div class="middle">
        <aside>Меню</aside>
        <main>Основной контент</main>
    </div>
    <footer>Подвал</footer>
</body>
</html>
