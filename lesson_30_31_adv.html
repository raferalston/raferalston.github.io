Управление с клавиатуры

средненовоеавтопроверка

Первый шаг к игре: квадрат #player должен двигаться стрелками. По нажатию → (event.key === 'ArrowRight') он сдвигается вправо на 20px, по ← — влево. Позицию храни в переменной x и меняй player.style.left.

Показать ответ (сначала попробуй сам!)
let player = document.querySelector('#player')
let x = 0

document.addEventListener('keydown', function (event) {
    if (event.key === 'ArrowRight') {
        x += 20
    } else if (event.key === 'ArrowLeft') {
        x -= 20
    }
    player.style.left = x + 'px'
})
