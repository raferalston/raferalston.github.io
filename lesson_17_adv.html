Здесь пишем только JavaScript. console.log() и alert() выводят результат в консоль под редактором, а prompt() откроет окошко для ввода. При проверке ответы на prompt() подставляются сами.

Окно с сообщением

легконовоеавтопроверка

Покажи окно alert() с текстом Добро пожаловать!, а потом выведи в консоль, сколько будет 2 + 2 (пусть посчитает JavaScript).

Показать ответ (сначала попробуй сам!)
alert('Добро пожаловать!')
console.log(2 + 2)
3

Меняем текст на странице

легконовоеавтопроверка

На странице есть заголовок <h1 id="title">. С помощью JavaScript поменяй его текст на Привет, JavaScript! и сделай его красным.

Подсказка

Текст меняется через title.textContent = ..., а цвет — через title.style.color = ...

Показать ответ (сначала попробуй сам!)
let title = document.querySelector('#title')
title.textContent = 'Привет, JavaScript!'
title.style.color = 'red'
4

Кнопка-приветствие

средненовоеавтопроверка

Когда пользователь нажимает на кнопку #hello, должно появляться окно с текстом Привет!

Подсказка

Используй button.addEventListener('click', function () { ... })

Показать ответ (сначала попробуй сам!)
let button = document.querySelector('#hello')

button.addEventListener('click', function () {
    alert('Привет!')
})
