Макет для трёх экранов

сложнов VS Code

В Figma нарисуй макет своего сайта-портфолио для трёх размеров экрана: ≥ 1200px (компьютер), 768px (планшет) и < 576px (телефон).

Материалы для макета — обязательно скачай!

🖥️ Это большое задание — делай его в VS Code на компьютере и открывай страницу в браузере. Не забудь выложить результат на свой сайт на GitHub!
