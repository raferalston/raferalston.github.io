HTML-структура по рисунку

легкоавтопроверка

Создай HTML-структуру своего сайта по рисунку-макету: заголовок, блоки с картинками (class="picture-1", class="picture-2"), блок с текстами (class="text-1", class="text-2") и кнопку.

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Структура html</title>
</head>
<body>
    <h1>Название</h1>
    <div>
        <div class="picture-1">
            <img src="img/lesson_6.jpg" alt="Тут будет первая картинка" width="200">
            <span>Lorem ipsum dolor sit amet consectetur adipisicing elit.</span>
        </div>
    </div>
    <div class="picture-2">
        <img src="img/lesson_6.jpg" alt="Тут будет вторая картинка" width="200">
    </div>
    <div>
        <span class="text-1">Lorem ipsum dolor sit amet consectetur adipisicing elit.</span>
        <span class="text-2">Deserunt modi tempore eligendi minus recusandae.</span>
    </div>
    <div>
        <button>Кнопка</button>
    </div>
</body>
</html>

Внутренняя ссылка

легкоавтопроверка

Внутренняя ссылка ведёт не на другую страницу, а к месту на этой же странице: href="#id-блока". Замени _______ так, чтобы ссылка «ВНИЗ» вела ко второму блоку, а «НАВЕРХ» — к первому. Покрути результат и понажимай ссылки!

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Ссылка внутри документа</title>
    <style>
        #first-section {
            height: 100vh;
            background-color: crimson;
        }
        #second-section {
            height: 100vh;
            background-color: #06ee72;
        }
        a {
            font-size: 4em;
            color: white;
        }
    </style>
</head>
<body>
    <div id="first-section">
        <a href="#second-section">ВНИЗ</a>
    </div>
    <div id="second-section">
        <a href="#first-section">НАВЕРХ</a>
    </div>
</body>
</html>

Селекторы class и id

легконовоеавтопроверка

Напиши стили, не меняя HTML:

  • элемент с id="main-title" — фиолетовый (purple)
  • все элементы с классом .important — жирные и с жёлтым фоном (yellow)
  • элементы с классом .hidden — спрятать (display: none)

Подсказка

Селектор класса начинается с точки: .important, селектор id — с решётки: #main-title.

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>

        #main-title { color: purple; }
        .important { font-weight: bold; background-color: yellow; }
        .hidden { display: none; }
    </style>
</head>
<body>
    <h1 id="main-title">Правила класса</h1>
    <p>Приходить вовремя.</p>
    <p class="important">Не шуметь на уроке!</p>
    <p>Делать домашку.</p>
    <p class="important">Сохранять код!</p>
    <p class="hidden">Этот текст должен исчезнуть</p>
</body>
</html>

Экран целиком: vh и vw

средненовоеавтопроверка

Сделай блок .hero высотой ровно в весь экран (100vh), а блок .half — шириной в половину экрана (50vw). Не забудь убрать отступы у body: margin: 0.

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>

        body { margin: 0; }
        .hero { background-color: #6d4aff; color: white; height: 100vh; }
        .half { background-color: #ff9f1c; width: 50vw; }
    </style>
</head>
<body>
    <div class="hero">Весь экран</div>
    <div class="half">Половина ширины</div>
</body>
</html>
