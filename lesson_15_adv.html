Познакомься с Bootstrap

легко

Открой сайт getbootstrap.com, найди раздел Components и посмотри, какие готовые элементы там есть.

Потом загляни в готовые макеты для Bootstrap и цветовые темы Bootswatch: чтобы сменить тему, достаточно поменять ссылку на CSS-файл.

2

Страница на Bootstrap

средненовоеавтопроверка

Подключи Bootstrap и собери страницу из готовых классов:

  • в <head> — <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
  • всё содержимое — внутри <div class="container">
  • кнопка с классами btn btn-primary
  • ряд row с тремя колонками col
  • цветная плашка alert alert-success

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
    <title>Моя страница</title>
</head>
<body>
    <div class="container">
        <h1>Мой первый сайт на Bootstrap</h1>
        <div class="alert alert-success">Ура, Bootstrap подключён!</div>
        <div class="row">
            <div class="col">Колонка 1</div>
            <div class="col">Колонка 2</div>
            <div class="col">Колонка 3</div>
        </div>
        <button class="btn btn-primary">Нажми меня</button>
    </div>
</body>
</html>
