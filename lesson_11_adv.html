Анимация «Привет мир!»

среднеавтопроверка

Сделай надпись, которая при загрузке страницы вырастает и получает фон.

👀 Открыть образец

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>Анимация</title>
    <style>
        body {
            display: flex;
            justify-content: center;
            align-items: center;
            height: 100vh;
            background-color: #78a8bc;
            overflow: hidden;
            margin: 0;
        }
        .container {
            font-size: 1em;
            color: white;
            animation: slideIn forwards 1s ease-in-out;
        }
        @keyframes slideIn {
            80% {
                font-size: 3em;
                padding: 2em;
            }
            100% {
                padding: 1.85em;
                font-size: 2.75em;
                background-color: darkslateblue;
                border-radius: 5px;
            }
        }
    </style>
</head>

<body>
<div class="container">
    Привет мир!
</div>
</body>

</html>

Подсказка

Показать ответ (сначала попробуй сам!)

            height: 100vh;
            background-color: #43dde6;

Бьющееся сердце

легконовоеавтопроверка

Сделай сердечко ❤️, которое бесконечно «бьётся»: увеличивается до scale(1.3) и обратно. Назови анимацию beat, длительность — 1s.

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>

        body { display: flex; justify-content: center; align-items: center; height: 100vh; margin: 0; }
        .heart { font-size: 100px; animation: beat 1s infinite; }
        @keyframes beat {
            0% { transform: scale(1); }
            50% { transform: scale(1.3); }
            100% { transform: scale(1); }
        }
    </style>
</head>
<body>
    <div class="heart">❤️</div>
</body>
</html>

Спиннер загрузки

средненовоеавтопроверка

Сделай круглый индикатор загрузки: блок .loader с рамкой, у которой одна сторона цветная, бесконечно вращается (rotate(360deg)) с равномерной скоростью (linear).

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>

        .loader {
            width: 60px;
            height: 60px;
            border: 8px solid #eee;
            border-top-color: #6d4aff;
            border-radius: 50%;
            animation: spin 1s linear infinite;
        }
        @keyframes spin {
            to { transform: rotate(360deg); }
        }
    </style>
</head>
<body>
    <div class="loader"></div>
</body>
</html>

Градиентный фон

легконовоеавтопроверка

Сделай у body фон-градиент из двух цветов с помощью linear-gradient(), а у кнопки .btn — градиент слева направо (to right).

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>

        body { height: 100vh; margin: 0; font-family: sans-serif; background: linear-gradient(#ffd23f, #ff4d8d); }
        .btn { border: 0; color: white; padding: 16px 32px; font-size: 18px; border-radius: 30px;
               background: linear-gradient(to right, #6d4aff, #19b8a6); }
    </style>
</head>
<body>
    <h1>Градиенты</h1>
    <button class="btn">Красивая кнопка</button>
</body>
</html>
