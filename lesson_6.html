Шпаргалка: display: flex включают у родителя. justify-content — выравнивание вдоль главной оси, align-items — поперёк, flex-direction: column — столбиком, flex-wrap: wrap — перенос на новую строку.

Ровно по центру

легконовоеавтопроверка

Поставь блок .box ровно в центр экрана с помощью flexbox. У body уже есть высота во весь экран — осталось включить flex и выровнять.

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>

        body { margin: 0; height: 100vh; background-color: #efeaff; display: flex; justify-content: center; align-items: center; }
        .box { width: 200px; padding: 30px; background-color: #6d4aff; color: white; text-align: center; border-radius: 16px; }
    </style>
</head>
<body>
    <div class="box">Я в центре!</div>
</body>
</html>

Меню в одну строку

средненовоеавтопроверка

Сделай меню: логотип слева, ссылки справа. Для nav используй display: flex и justify-content: space-between, а для списка ссылок .links — тоже flex с промежутком gap: 20px.

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>

        body { margin: 0; font-family: sans-serif; }
        nav { background-color: #1f1b3d; padding: 16px 24px; display: flex; justify-content: space-between; align-items: center; }
        .logo { color: #ffd23f; font-weight: bold; font-size: 22px; }
        .links { display: flex; gap: 20px; }
        .links a { color: white; text-decoration: none; }
    </style>
</head>
<body>
    <nav>
        <div class="logo">🚀 Космо</div>
        <div class="links">
            <a href="#">Главная</a>
            <a href="#">Игры</a>
            <a href="#">Контакты</a>
        </div>
    </nav>
</body>
</html>

Галерея в три колонки

средненовоеавтопроверка

Шесть блоков .item должны стоять по три в ряд. Контейнеру .gallery — display: flex и flex-wrap: wrap, а каждому .item — ширину 33.33%.

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>

        body { margin: 0; }
        .gallery { display: flex; flex-wrap: wrap; }
        .item { box-sizing: border-box; width: 33.33%; font-size: 60px; text-align: center; padding: 20px; border: 2px solid white; background-color: #ffe6f0; }
    </style>
</head>
<body>
    <div class="gallery">
        <div class="item">🍎</div>
        <div class="item">🍌</div>
        <div class="item">🍇</div>
        <div class="item">🍉</div>
        <div class="item">🍓</div>
        <div class="item">🥝</div>
    </div>
</body>
</html>
