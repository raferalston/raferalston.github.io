Сумма или произведение

легкоавтопроверка

Программа спрашивает у пользователя два числа. Если их сумма больше 1000 — выводит Сумма этих чисел: …, иначе — Произведение этих чисел: …

Показать ответ (сначала попробуй сам!)
let firstNumber = Number(prompt('Введите первое число: '));
let secondNumber = Number(prompt('Введите второе число: '));
let result = firstNumber + secondNumber

if (result > 1000) {
    alert('Сумма этих чисел: ' + result)
} else {
    result = firstNumber * secondNumber
    alert('Произведение этих чисел: ' + result)
}

Проверка имени персонажа

среднеавтопроверка

Программа спрашивает имя персонажа и отвечает по-разному:

  • ничего не ввели — Вы не ввели имя!
  • от 1 до 3 символов — …слишком короткое…
  • от 4 до 6 символов — <имя> это имя идеально вам подходит!
  • больше 6 символов — …слишком длинное…

Показать ответ (сначала попробуй сам!)
let name = prompt('Введите имя персонажа и мы проверим, подходит ли оно вам: ')

if (name.length === 0) {
    alert('Вы не ввели имя!')
} else if (name.length <= 3) {
    alert('Оно слишком короткое, попробуйте ввести больше чем ' + name.length + ' символа')
} else if (name.length <= 6) {
    alert(name + ' это имя идеально вам подходит!')
} else {
    alert('Оно слишком длинное, попробуйте ввести меньше чем ' + name.length + ' символов')
}
3

Загадка

легкоавтопроверка

Программа задаёт загадку и отвечает Правильный ответ! или Ответ неверный, правильный ответ: фонтан. Ответ «Фонтан» с большой буквы тоже должен засчитываться.

Подсказка

Приведи ответ к маленьким буквам: answer.toLowerCase()

Показать ответ (сначала попробуй сам!)
let question = ['Странный дождь порой идёт: сотней струй он кверху бьёт.', 'фонтан']

let answer = prompt('Отгадайте загадку: ' + question[0] + ' Ваш ответ: ')

if (answer.toLowerCase() === question[1]) {
    alert('Правильный ответ!')
} else {
    alert('Ответ неверный, правильный ответ: ' + question[1])
}
4

Чётное или нечётное

легконовоеавтопроверка

Спроси у пользователя число и выведи Число чётное или Число нечётное.

Подсказка

Остаток от деления на 2: number % 2 === 0 — значит, чётное.

Показать ответ (сначала попробуй сам!)
let number = Number(prompt('Введите число: '))

if (number % 2 === 0) {
    alert('Число чётное')
} else {
    alert('Число нечётное')
}

Оценка за тест

средненовоеавтопроверка

Спроси, сколько баллов из 100 набрал ученик, и выведи оценку:

  • 90 и больше — Оценка: 5
  • 70–89 — Оценка: 4
  • 50–69 — Оценка: 3
  • меньше 50 — Оценка: 2

Показать ответ (сначала попробуй сам!)
let score = Number(prompt('Сколько баллов ты набрал? '))

if (score >= 90) {
    alert('Оценка: 5')
} else if (score >= 70) {
    alert('Оценка: 4')
} else if (score >= 50) {
    alert('Оценка: 3')
} else {
    alert('Оценка: 2')
}

Високосный год

сложноновоеавтопроверка

Год високосный, если он делится на 4, но не делится на 100, или если делится на 400. Спроси год и выведи Год високосный или Год не високосный.

Подсказка

Логические операторы: && — «и», || — «или».

Показать ответ (сначала попробуй сам!)
let year = Number(prompt('Введите год: '))

if ((year % 4 === 0 && year % 100 !== 0) || year % 400 === 0) {
    alert('Год високосный')
} else {
    alert('Год не високосный')
}
