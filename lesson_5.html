Выкладываем сайт в интернет. Позиционирование

Публикуем свой сайт на GitHub Pages, чтобы домашку можно было открыть с любого устройства, и учимся ставить элементы в любое место страницы.

🚀Задания

1

Выложи домашку на свой сайт

легков VS Code

По инструкции создай свой сайт на GitHub Pages и добавь на него задания:

  • точную копию страницы-загадки (урок 2)
  • страницу со стилями (урок 3)
  • HTML-структуру своей странички (урок 4)

На главной странице сайта сделай ссылки на все задания — как на картинке.

🖥️ Это большое задание — делай его в VS Code на компьютере и открывай страницу в браузере. Не забудь выложить результат на свой сайт на GitHub!

2

Расставь квадраты

среднеавтопроверка

Расположи четыре цветных квадрата лесенкой, как на картинке. Используй position: absolute и свойства top, left.

А потом разгадай шифр сейфа — и получи подсказку!

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>Тренируем позиционирование элементов</title>
    <style>
    .f {
        position: absolute;
        top: 10%;
        left: 10%;
        width: 10vw;
        height: 10vh;
        background-color: darkorange;
    }
    .s {
        position: absolute;
        top: 15%;
        left: 15%;
        width: 10vw;
        height: 10vh;
        background-color: green;
    }
    .t {
        position: absolute;
        top: 20%;
        left: 20%;
        width: 10vw;
        height: 10vh;
        background-color: blue;
    }
    .fo {
        position: absolute;
        top: 25%;
        left: 25%;
        width: 10vw;
        height: 10vh;
        background-color: rebeccapurple;
    }    
    </style>
</head>
<body>
    <div class="f"></div>
    <div class="s"></div>
    <div class="t"></div>
    <div class="fo"></div>
</body>
</html>

Значок на аватарке

средненовоеавтопроверка

Сделай красный кружок-значок с числом 3 в правом верхнем углу аватарки, как у сообщений в мессенджерах. Родителю .avatar дай position: relative, а значку .badge — position: absolute, top: 0, right: 0.

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>

        .avatar { width: 120px; height: 120px; font-size: 90px; text-align: center; background-color: #eee; border-radius: 50%; position: relative; }
        .badge { background-color: red; color: white; font-size: 20px; width: 34px; height: 34px; line-height: 34px; border-radius: 50%; position: absolute; top: 0; right: 0; }
    </style>
</head>
<body>
    <div class="avatar">
        😺
        <span class="badge">3</span>
    </div>
</body>
</html>
