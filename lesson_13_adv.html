Звездопад

сложноавтопроверка

Создай сайт, как на анимации: фон с ночным небом стоит на месте при прокрутке (параллакс), а сверху падают звёзды. Картинки: img/night.jpg и img/night_flip.jpg.

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>Звездопад</title>
    <style>
    body {
        margin: 0;
        overflow-x: hidden;
    }
    .top {
        overflow-x: hidden;
        height: 100vh;
        display: flex;
        justify-content: center;
        align-items: center;
        background-image: url('img/night.jpg');
        background-attachment: fixed;
        background-position: center;
        background-repeat: no-repeat;
        background-size: cover;

    }
    .bottom {
        overflow-x: hidden;
        height: 100vh;
        display: block;
        background-image: url('img/night_flip.jpg');
        background-attachment: fixed;
        background-position: center;
        background-repeat: no-repeat;
        background-size: cover;
    }    
    @keyframes falling_down {
        0% {
            top: -5px;
        }        
        100% {
            top: 199vh;
        }
    }  
    .star {
        position: absolute;
        background-color: white;
        top: 0;
    }
    .star:nth-child(1) {
        width: 3px;
        height: 3px;
        left: 4vw;
        animation: falling_down 7s .2s linear infinite;
    }
    .star:nth-child(2) {
        width: 3px;

    }
    .star:nth-child(3) {
        width: 3px;
        height: 3px;
        left: 44vw;
        animation: falling_down 6.5s 2s linear infinite;
    }
    .star:nth-child(4) {
        width: 3px;
        height: 3px;
        left: 62vw;
        animation: falling_down 6s .9s linear infinite;
    }
    .star:nth-child(5) {
        width: 3px;
        height: 3px;
        left: 82vw;
        animation: falling_down 5.75s 1s linear infinite;
    }                   
    .title {
        padding: 2em;

SVG-смайлик

средненовоеавтопроверка

Нарисуй смайлик тегом <svg width="200" height="200">: жёлтое лицо и два глаза — это три <circle>, а улыбку сделай через <path> или <line>.

Подсказка

Улыбка-дуга: <path d="M 60 120 Q 100 160 140 120" stroke="black" stroke-width="6" fill="none" />

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
</head>
<body>
    <svg width="200" height="200">
        <circle cx="100" cy="100" r="90" fill="gold" />
        <circle cx="70" cy="80" r="12" fill="black" />
        <circle cx="130" cy="80" r="12" fill="black" />
        <path d="M 60 120 Q 100 160 140 120" stroke="black" stroke-width="6" fill="none" />
    </svg>
</body>
</html>

Параллакс-блок

легконовоеавтопроверка

Сделай блок .parallax высотой 400px с картинкой img/night.jpg на фоне. Фон должен стоять на месте при прокрутке (background-attachment: fixed) и заполнять блок (background-size: cover). Прокрути результат!

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>

        body { margin: 0; font-family: sans-serif; }
        .text { height: 400px; font-size: 30px; padding: 20px; }
        .parallax { height: 400px; background-image: url('img/night.jpg'); background-attachment: fixed; background-size: cover; background-position: center; }
    </style>
</head>
<body>
    <p class="text">Прокручивай вниз...</p>
    <div class="parallax"></div>
    <p class="text">А теперь вверх!</p>
</body>
</html>
