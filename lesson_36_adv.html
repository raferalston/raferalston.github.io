🚀Задания

1

Проверь сайт по чек-листу

среднев VS Code

Пройди по чек-листу выше. Открой свой сайт в Chrome, нажми F12 → вкладка Lighthouse → Analyze page load. Исправь всё, что подсветится красным, и добейся хотя бы 90 баллов.

🖥️ Это большое задание — делай его в VS Code на компьютере и открывай страницу в браузере. Не забудь выложить результат на свой сайт на GitHub!

2

Опубликуй портфолио

сложнов VS Code

Сожми картинки (squoosh.app, compressjpeg, compresspng) и выложи сайт на GitHub Pages или хостинг. Пришли ссылку преподавателю!

🖥️ Это большое задание — делай его в VS Code на компьютере и открывай страницу в браузере. Не забудь выложить результат на свой сайт на GitHub!

3

Картинка для любого экрана

средненовоеавтопроверка

С помощью тега <picture> покажи на узких экранах (до 600px) картинку img/35_phone.png, а на остальных — img/35_tablet.png. У <img> обязательно заполни alt. Как это работает.

Показать ответ (сначала попробуй сам!)
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
</head>
<body>
    <picture>
        <source media="(max-width: 600px)" srcset="img/35_phone.png">
        <img src="img/35_tablet.png" alt="Макет моего сайта" width="300">
    </picture>
</body>
</html>
